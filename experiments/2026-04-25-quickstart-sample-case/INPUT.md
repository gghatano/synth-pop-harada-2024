# 入力データの説明

## 使用データ

- **データ名**: synthpop-jp 同梱サンプルデータ（`data/sample_case/`）
- **バージョン**: リポジトリ初期同梱版（2026-04-24 時点）
- **取得方法**: リポジトリ内に直接含まれるダミーデータ。実際の国勢調査データではない
- **世帯数**: 100 世帯（ダミー入力）

## ファイル一覧

| ファイル名 | 内容 |
|---|---|
| `family_type_counts.csv` | 家族構成タイプ別の世帯数（入力統計） |
| `household_size_dist.csv` | 世帯規模（人数）の分布（入力統計） |
| `age_sex_dist.csv` | 年齢・性別の分布（入力統計） |

## 注意事項

このデータは **機能検証用のダミーデータ** です。
実際の国勢調査データとは異なります。
実データを使った検証は Phase 2 以降で実施します。

## 生成コマンド

```bash
uv run synthpop-jp quickstart
```

設定ファイル: `config.yaml`（`configs/base.yaml` のコピー）
出力先: `outputs/quickstart/`
