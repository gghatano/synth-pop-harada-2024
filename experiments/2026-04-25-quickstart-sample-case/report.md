## 非技術者向け要約

合成人口（統計に合わせて人工的に作成した個票データ）を生成しました。
ダミー入力として 100 世帯を設定し、合計 266 人分の個人データを出力しました。

最も多い家族構成は「夫婦と子ども」で、全 100 世帯中 30 世帯（30%）を占めます。
単身世帯（20 世帯）と夫婦のみ世帯（24 世帯）が続きます。

個人の内訳は男性 153 人、女性 113 人です。

現在は初期生成（SA 最適化なし）の段階です。
焼きなまし法（SA: 徐々に解を改善する最適化手法）による調整は Phase 2 で実施します。

次のステップでは年齢・世帯規模の分布を実データに近づける調整を行います。
その結果も同じ形式のレポートでお届けします。

## 目的

この実験は Issue #38「HTML レポート基盤」の実例レポート（成功条件の一つ）として実施した。
生成パイプライン（`src/synthpop_jp/reports/`）が正常に動作し、経営層が 30 秒で読める
HTML レポートを出力できることを確認することが目的である。

## 仮説

- Phase 1 の初期生成は SA 最適化を経ないため、家族構成の分布は入力統計と一致する
- plotly 図（円グラフ・人口ピラミッド・整合性棒グラフ）が self-contained HTML に正しく埋め込まれる
- ファイルサイズは plotly inline JS を含んでも 1MB 以内に収まる

## 解釈

初期生成（Phase 1）として想定通りの結果が得られた。
家族構成の分布は入力統計と完全一致しており、
SA 最適化を経ていない段階では統計整合性が担保されることを確認できた。

plotly 図の埋め込みも正常に動作した。
self-contained（外部依存ゼロ）の HTML として出力されており、
メール添付で経営層に送付できる状態になっている。

## 制約

- ダミーデータ（100 世帯）を使用しており、実際の統計とは異なる
- SA 最適化を経ていないため、年齢分布は入力統計と完全には一致しない
- 個人属性（職業・収入等）は未実装（Phase 3 以降で追加予定）

## 再現手順

```bash
# 1. quickstart でサンプルデータを生成する（約 0.25 秒）
uv run synthpop-jp quickstart

# 2. HTML レポートを生成する
uv run python scripts/generate_sample_report.py
```

- Python: 3.12.12
- 主要依存: plotly 6.7.0, pandas 2.x
- 実行時間目安: 約 2〜3 秒
